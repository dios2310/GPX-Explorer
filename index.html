Les tracés importés sont enregistrés dans le stockage local de cet appareil lorsqu'il est disponible. Utilise Sauvegarder pour conserver une copie. Les fonds de carte sont chargés depuis OpenStreetMap ou l’IGN si la connexion l’autorise. Pince et tourne avec deux doigts pour zoomer ou orienter la carte. Appuie sur N pour retrouver le nord. La détection est une estimation GPS, non une identification officielle des chemins.
